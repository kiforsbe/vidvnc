Measurement notes & logs

Graphs show the last two minutes. — means unavailable. Red status means samples are stale, not proof of a specific failure.

Burst peaks cover the last reporting interval. ICE input includes encrypted media and control traffic, measured before the network sink—not on the wire. Queue values are once-per-second samples, not peak backlog or OS socket buffers.

Capture gaps and frames pending are not confirmed drops. QoS drops are the largest per-element reported cumulative count, not an end-to-end sum. Encode time is input-to-output residence time, not GPU-only time. Jitter-buffer time and RTT are not glass-to-glass latency.

Logs: %LOCALAPPDATA%/VidVNC/logs (or VIDVNC_LOG_DIR) · Local server view only · No passwords, input contents, video, SDP or network addresses logged.
