# POC-01 native media continuation

Supersedes the bootstrap-only execution scope of the September 9 plan.
User-approved scope: Windows 11 25H2+, NVIDIA hardware H.264, one primary
monitor, self-served browser, generated password, mouse and keyboard.
No GDI/MJPEG or software-encoding fallback. No subagents.

Dependency source: https://gstreamer.freedesktop.org/download/download.html
GStreamer 1.28 uses Inno Setup; `/TYPE=devel /CURRENTUSER /DIR=...` installs
headers and runtime together. The SDK is installed under `poc-01/.deps` and
is not intended to be committed. The installer may register its uninstaller
and user environment settings; it is not merely archive extraction.

The current Node scaffold and historical Windows fallback are not a completed
POC. Prior fallback capture failure did not establish that the host is headless.
